# Bread Guy photo assets

Product photography for the Bread Guy site.

- Files in this folder are rectangular photos (WebP + JPEG).
- `cutouts/` holds background-removed transparent WebPs, used for
  collage layouts.
- See `README-mapping-and-menu-audit.md` for what each file is,
  which product it belongs to, and which products still have no photo.

All photos are the bakery's own. No stock, no AI-generated or
AI-relit imagery.
